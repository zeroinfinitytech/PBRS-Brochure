# PBRS Course Prospectus: live editable brochure

Open the page, press **Review**, then tap any text or photo to leave a note., **Send feedback** to email the Zero Infinity team, **Download PDF** for the print file.

Edits are kept in your browser; **Export edits** saves them as a file and **Import edits** loads one.
Built by Zero Infinity Infotech for PBRS. Rebuild with `python make_site.py` (needs Python and Pillow).
